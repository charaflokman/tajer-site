Windows a bloqué le fichier ? Pas de panique

Tajer est sain, mais il est récent et pas encore signé numériquement : Windows ou l'antivirus le croit inconnu. Voici trois solutions, puis comment vérifier que le fichier est intact.

1) Message bleu « Windows protected your PC »

Cliquez « More info » (Informations complémentaires), puis le bouton « Run anyway » (Exécuter quand même) apparaît. Cliquez dessus.

2) Le fichier ne s'ouvre pas

Clic droit sur le fichier, « Properties » (Propriétés). En bas, cochez « Unblock » (Débloquer), puis « OK ». Relancez le fichier.

3) L'antivirus a supprimé le fichier ou donne une alerte

C'est une fausse alerte fréquente pour les logiciels récents. Vérifiez l'empreinte (section suivante) ; si elle correspond, autorisez le fichier dans « Menaces autorisées » ou ajoutez-le aux exclusions de l'antivirus, puis retéléchargez.

Comment vérifier le fichier ? (SHA256)

  1. Ouvrez le dossier Téléchargements, cliquez dans la barre d'adresse, tapez cmd puis Entrée.
  2. Tapez la commande suivante (changez le nom du fichier) puis Entrée :
    certutil -hashfile Tajer-1.0.8-win64.exe SHA256
  3. Comparez la longue suite de chiffres et lettres avec celle affichée près du bouton de téléchargement (ou dans SHA256SUMS.txt). Si tout correspond, le fichier est intact. Sinon, ne le lancez pas et retéléchargez.
