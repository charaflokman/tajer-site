Windows blocked the file? Don't worry

Tajer is safe, but it is new and not digitally signed yet, so Windows or your antivirus treats it as unknown. Here are three fixes, then how to check the file is genuine.

1) Blue message "Windows protected your PC"

Click "More info", then the "Run anyway" button appears. Click it.

2) The file will not open

Right-click the file, choose "Properties". At the bottom tick "Unblock", then "OK". Run the file again.

3) The antivirus deleted the file or warned you

This is a common false alarm for new software. Check the fingerprint (next section); if it matches, allow the file in the antivirus "Allowed threats" or add it to the exclusions, then download again.

How do I check the file is genuine? (SHA256)

  1. Open the Downloads folder, click the address bar, type cmd and press Enter.
  2. Type this command (change the file name) and press Enter:
    certutil -hashfile Tajer-1.0.7-win64.exe SHA256
  3. Compare the long string with the one shown next to the download button (or in SHA256SUMS.txt). If all of it matches, the file is genuine. If not, do not run it and download again.
